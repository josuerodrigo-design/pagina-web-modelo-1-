# 💻 Projeto Front-End: Aprimorando Interfaces Digitais

Este projeto foi desenvolvido como parte prática da **Unidade 3** do curso **Alura Start**. O objetivo principal foi aplicar técnicas avançadas de estruturação web, estilização moderna e interatividade para criar uma interface limpa, acessível e totalmente responsiva.

---

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização moderna utilizando variáveis nativas, efeitos de sombra e layouts flexíveis.
*   **JavaScript (Vanilla):** Manipulação do DOM para alternância dinâmica de temas.

---

## 🎯 Conceitos Aplicados (Requisitos da Unidade)

*   **Arquivos Independentes:** Separação clara de responsabilidades com arquivos estruturados em pastas específicas (`/css` e `/js`).
*   **Layouts Responsivos com Flexbox:** Alinhamento e distribuição de elementos que se adaptam automaticamente a telas de computadores, tablets e celulares.
*   **Atributos e Classes:** Uso estratégico de classes utilitárias (ex: `.card-shadow`) e atributos customizados (`data-theme`) para manipulação de estilos.
*   **Cores, Temas e Tema Escuro:** Implementação de um sistema de variáveis CSS (`:root`) para alternar dinamicamente entre os modos claro (*Light Mode*) e escuro (*Dark Mode*).
*   **Efeitos e Sombras:** Aplicação de profundidade visual nos elementos utilizando `box-shadow` de forma suave.

---

## 📂 Estrutura do Repositório

```text
├── 📄 index.html      # Estrutura principal do site
├── 📂 css/
│   └── 📄 style.css   # Estilos globais, variáveis de tema e Flexbox
└── 📂 js/
    └── 📄 script.js   # Lógica de alternância do tema (Light/Dark)
```

---

## ⚙️ Como Executar o Projeto

1. Faça o clone deste repositório ou baixe os arquivos.
2. Abra a pasta do projeto no seu editor de código (como o VS Code).
3. Abra o arquivo `index.html` diretamente no seu navegador ou utilize a extensão **Live Server** para rodar localmente.
4. Clique no botão **"Alternar Tema"** no topo da página para testar o Dark Mode!
